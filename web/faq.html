适用于哪个 Python 版本？

原文以 Python 3.12 为基准。要求高于 3.9 的 features 会在注释或括号中标明；原文说明有两项需要 3.10。

截至 2024 年 3 月 12 日，所用 libraries 中，最新版要求高于 Python 3.8 的只有 NumPy、Pandas 和 Matplotlib，均要求 Python 3.9。本文介绍 NumPy 2.0（2024 年 6 月 16 日发布）及以上版本，以及 Pandas 2.0（2023 年 4 月 3 日发布）及以上版本。

如何使用？

本文用精简的说明和短示例，便于通过 Ctrl+F / ⌘F 查找内容。网页提供章节目录；搜索 #<name> 可定位主要标题。点击标题旁的 #，再复制地址，即可获取该章节的链接。在文本编辑器中，可开启 regular expression 搜索并输入 ^<name> 查找标题。

阅读时可以打开 Python console，测试小段代码、通过 code completion 查看 module 提供的 functions，并使用 help(<module/object/function/type/str>)。仍有疑问时，可以搜索 python docs <module/function> 查阅 Python docs。

原作者曾使用 ptpython REPL，支持多行编辑、syntax validation、类似 IDE 的 autocompletion 和 syntax highlighting，可用 pip3 install ptpython 安装；后来改用响应更快的 IPython REPL，可用 pip3 install ipython 安装。

<type> 表示什么？

它是 object 的 placeholder，需要替换成返回或属于该 type 的 expression、literal 或 variable。若出现在 assignment（=）左侧，则表示右侧 expression 创建或返回的 object 的 type。

为什么采用 <type> 这种写法？

它能减少示例中的歧义。

<el> 到底是什么？

El 是 element 的缩写，可以是任意 object，通常表示 collection 中的一个 item。

<collection> 到底是什么？

Collection 是原作者对 iterable object 的称呼。在 Python 中，只要 object 定义了 iter() 或 getitem() special method，就可以迭代。按约定，<object>.__iter__() 返回遍历其 items 的 iterator，<object>.__getitem__(<index>) 返回指定 index 处的 item。原作者觉得 collection 比 iterable 更直观，因此采用这一称呼。

Iterable abstract base class 与这个定义并不完全一致：isinstance(<object>, collections.abc.Iterable) 只检查 iter() special method，不检查 getitem()。

Python 术语表未定义 collection，但提供了 Collection abstract base class。对于同时定义 len()、iter() 和 contains() special methods 的 object，isinstance(<object>, collections.abc.Collection) 返回 True。<object>.__len__() 应返回 elements 的数量，<object>.__contains__(<el>) 应检查是否包含指定 element。
